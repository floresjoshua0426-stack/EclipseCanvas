PLAY FIRST / LEARN AS YOU GO

Easy to start.
Room to master.

Your first minute

WASD + mouse move and look. Space jumps. LMB / RMB light / heavy attack. Z dodges, X counters and E interacts.

1–8 select a skill; Q casts. 0 cycles three pages covering all 24 techniques. These are the defaults—not a mandatory layout.

Make the controls yours

F1 → Controls → Edit computer keys & 24-skill quickbar. Search, rebind a single key or mouse button, assign techniques, then Apply. Cancel leaves the current controls untouched.

Conflicts are rejected. F1 stays as menu recovery. Optional quick-cast starts OFF; ultimates remain separate. The current bar uses keys, not drag-and-drop.

A5.5 / ONE COHERENT WORLD CLOCK

A world that changes
around your next move.

Day, night and shelter

The existing native day/night clock now drives the Unreal sun, ambient light, fog and exposure. The HUD shows local time and weather. Terrain roughness follows wetness; shared indoor wall materials remain dry.

Civilians with intact homes can head home in heavy weather and at night, using existing routines and movement. Pausing also pauses the native clock.

Readable impact

Confirmed damage adds a small feet-anchored upper-body reaction. Hit sounds and optional rumble follow real native contact events, without an extra menu click.

This is original procedural presentation, not a new AAA skeletal animation library. Engine compilation, rendered lighting and Iris Xe performance still need device acceptance.

THE GAME / CHARGE HAS CONSEQUENCES

Power you can measure.
Reactions you can test.

One charge, one output budget

Ultimate charge now scales damage, local radius and environmental strength together. Cover is checked before walls collapse; radial falloff reduces edge damage. Changing the loadout or effective level cancels the charge instead of exchanging it for a stronger move.

Relic finishers scale with level instead of dealing an unconditional 10,000 damage. Armed planetary strikes require level 2,000, full charge and a destructive family; support skills do not secretly destroy worlds.

Bounded debris and water

Nearby rubble receives size-sensitive, capped impulses. Wet basins emit short-lived, shore-tapered ripples without creating extra water; submerged dense debris slows and sinks.

Local effects stay bounded for Fidelity. These are gameplay approximations—not measured blast physics, a fluid solver, or full planetary fracture. The existing population caps and species are preserved rather than inflated beyond the laptop budget.

The tier names describe progression and permissions. Local blasts stay under 30 metres. A planetary strike changes saved surface state; Universal and System do not mean physically simulating the destruction of every distant object. The protected level-7,000 world reset remains separate.

05 / KNOW WHAT YOU ARE GETTING

Built to grow. Clearly labelled.

What is new in A5.5—and what is retained?

65 editable computer binding rows, protected F1 menu recovery, conflict rejection, three assignable 8-slot quickbar pages, optional quick-cast and a separate backed-up preference profile. Existing controller controls and the HUD layout remain.

The native clock/weather now drive the Unreal lighting; existing lit armor replaces the fixed unlit character ramp. Civilians receive home-rest priorities for night and severe weather. Confirmed native damage drives small procedural reactions and bounded contact feedback.

The 0.35-second native combat buffer, forms, resident identity/resurrection, optional model chat, audio, weapons and prototype ultimates remain. The A5.4 CharacterMovement/GAS lab remains separate and opt-in. This is not a compiled Windows player, a new AAA art library or a claim of fully simulated planetary physics.

What has—and has not—been tested?

Portable native gameplay and geometry tests, local updater/packaging tests and browser-interface tests accompany the source. Synthetic build-output fixtures are labelled as such. They do not establish an Unreal build, shader compilation, rendered quality or frame rate on your laptop.

Historical A5.5 verification includes actual portable native controls/clock/weather/save tests, Python/filesystem and explicit Unreal adapters, browser interaction with mocked release responses, and final archive byte delivery. Older tests are retained as regression coverage. These are not Unreal screenshots, real model inference, physical haptics or laptop FPS measurements.

Controller and graphics compatibility

The Fidelity profile targets Intel Iris Xe through DX11/SM5, TAA upsampling and a 30 FPS cap. The cap is not a guaranteed minimum. A bounded frame-window policy can reduce scene resolution and near shadows; it never changes worlds, save files or gameplay rules.

Use a USB data cable for a first controller test. Standard gamepad bindings, live axis/button display and reconnect safety are included. PlayStation controllers use a compatible input layer such as Steam Input; PS Remote Play is console streaming, not a Windows gamepad driver. The package includes offline controller help. Physical Bluetooth, adaptive triggers and advanced haptics are not certified.

Owner / developer source and setup

The complete THE GAME source is supplied separately. Keep a working prepared version and use the new Update Center to stage a separate update copy. For a clean start, extract all files into a new folder and open EclipseGame/START_HERE.cmd. Installed Unreal 5.8.3 and its Windows C++ toolchain are required. No older prepared game is needed. To preserve an existing prepared project and progress, use this THE GAME package’s OPEN_UPDATE_CENTER.cmd and choose the full THE GAME ZIP.

After a successful local build and playtest, close Unreal and choose Build Public Windows Game ZIP. This creates a separate Shipping package; it does not upload anything. PUBLISH_PLAYTESTED_BUILD.cmd validates the package and guides publication. Only publish a build you actually extracted and played.
