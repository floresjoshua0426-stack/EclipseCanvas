04 / KNOW WHAT YOU ARE GETTING

Built to grow. Clearly labelled.

What changed in A5?

A complete A4-derived source base with the material readback repair, fresh-output setup validation, a narrow recovery path for the observed late Python shutdown crash, and one clean-start command. Normal play sessions disable editor Python.

Human, Vampire and Werewolf lineages retain every original power. The supernatural lineages add three selectable techniques each: four adapt existing safe movement/scan/gravity actions and two add temporary combat buffs. Style, build, colors and eyes remain independent.

Optional stylized blood and arm loss affect supported biological faction actors on melee defeat. This is not anatomical simulation or a copied franchise combat system. A frame-window guardian can lower the rendering budget in two steps; input recovery clears held buttons and waits for neutral controls.

Character art remains original procedural geometry, not photorealistic scans or motion capture. A5 has not yet been rendered or hardware-playtested in the build environment.

What has—and has not—been tested?

Portable native gameplay and geometry tests, local updater/packaging tests and browser-interface tests accompany the source. Synthetic build-output fixtures are labelled as such. They do not establish an Unreal build, shader compilation, rendered quality or frame rate on your laptop.

A public player must be built, cooked and playtested on Windows before publication. The site only offers a direct player download after finding a correctly named uploaded release asset. That naming check is not a code-signing or hardware-compatibility certificate.

Controller and graphics compatibility

The Fidelity profile targets Intel Iris Xe through DX11/SM5, TAA upsampling and a 30 FPS cap. The cap is not a guaranteed minimum. A bounded frame-window policy can reduce scene resolution and near shadows; it never changes worlds, save files or gameplay rules.

Use a USB data cable for a first controller test. Standard gamepad bindings, live axis/button display and reconnect safety are included. PlayStation controllers use a compatible input layer such as Steam Input; PS Remote Play is console streaming, not a Windows gamepad driver. The package includes offline controller help. Physical Bluetooth, adaptive triggers and advanced haptics are not certified.

Owner / developer source and setup

The complete A5 source is supplied separately. For a clean start, extract all files into a new folder and open EclipseGame/START_HERE.cmd. Installed Unreal 5.8.3 and its Windows C++ toolchain are required. No older prepared game is needed. To preserve an existing prepared project and progress, use this A5 package’s OPEN_UPDATE_CENTER.cmd and choose the full A5 ZIP.

After a successful local build and playtest, close Unreal and choose Build Public Windows Game ZIP. This creates a separate Shipping package; it does not upload anything. PUBLISH_PLAYTESTED_BUILD.cmd validates the package and guides publication. Only publish a build you actually extracted and played.
